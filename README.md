# One-Line Office Joke: 24-Hour Sprint

Entry for the make.fun bounty "One-Line Office Joke: 24-Hour Sprint" — one single-line joke about office life (146 characters).

The line: "The meeting could have been an email, but then nobody would get to say 'let's circle back' while staring at a spreadsheet like it owes them money."

`main.ts` writes the joke to `/output/entry.txt` (UTF-8, 1–200 chars, single line, not only whitespace), with a byte-length gate and a round-trip verification that reads the file back and confirms it is byte-identical.
